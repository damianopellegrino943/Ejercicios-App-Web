Ejercicio 2: Lista de Tareas Pendientes
Descripción:
Diseñar una página para gestionar una lista de tareas pendientes. La página debe tener un
formulario que permita al usuario agregar nuevas tareas. Las tareas agregadas deben
mostrarse en una lista debajo del formulario.
Requisitos:
- Utilizar etiquetas HTML para crear la estructura del formulario y la lista de tareas.
- Aplicar estilos CSS para darle un diseño agradable y funcional a la página.
- La lista de tareas debe estar ordenada sin viñetas y debe mostrar cada tarea con un fondo
diferente.
- Cada tarea en la lista debe tener un botón para eliminarla
