Ejercicio 1: Página de Registro de Usuarios
Descripción:
Crear una página de registro de usuarios utilizando HTML y CSS. La página debe tener un
formulario que permita al usuario ingresar su nombre de usuario, correo electrónico y
contraseña. El formulario debe tener un botón para enviar los datos.
Requisitos:
- Utilizar etiquetas HTML semánticas para estructurar la página.
- Aplicar estilos CSS para mejorar la apariencia de la página.
- El formulario debe tener campos para nombre de usuario, correo electrónico y contraseña.
- El botón de envío debe cambiar de color al pasar el cursor sobre él.
